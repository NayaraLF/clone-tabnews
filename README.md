# clone-tabnews

Projeto de estudo com o objetivo de aprimorar conhecimentos em programação e desenvolvimento web através da implementação de um clone de funcionalidades do site TabNews.

## Tecnologias Utilizadas

A arquitetura do projeto é baseada em um conjunto de tecnologias modernas, abrangendo frontend, backend, banco de dados, testes e infraestrutura.

### Frontend

- **React**: Biblioteca JavaScript para a construção de interfaces de usuário reativas e componentizadas.
- **Next.js**: Framework sobre React que habilita funcionalidades como renderização no lado do servidor (SSR) e criação de APIs, otimizando a performance e o desenvolvimento. [8, 9, 10]

### Backend

- **Node.js**: Ambiente de execução JavaScript que permite a construção de aplicações de backend eficientes e escaláveis.

### Banco de Dados

- **PostgreSQL**: Sistema de gerenciamento de banco de dados relacional de código aberto, escolhido pela sua robustez e confiabilidade. [3, 5, 6]

### Testes

- **Jest**: Framework de testes para JavaScript utilizado para garantir a qualidade e o correto funcionamento do código.

### Qualidade de Código

- **Prettier**: Ferramenta de formatação de código que garante um estilo consistente e legível em toda a base de código.

### Infraestrutura e Versionamento

- **Docker**: Plataforma de containerização utilizada para criar, empacotar e distribuir a aplicação e seus serviços em ambientes isolados. [1, 2, 4]
- **Git**: Sistema de controle de versão distribuído para o gerenciamento do código-fonte.
